Duas proteções antes do Azure

1 · Permissão

Papel Reader

O próprio Azure recusa qualquer escrita. É a proteção mais forte.

2 · Hook

Hook-freio

O Claude Code barra o comando antes de rodar:

az … create · delete · update · set
New-Az* · Remove-Az* · az deployment
terraform apply · destroy

Passam: show, list, graph query, account show.

Teste: az group delete --name nao-existe-xyz --yes tem que ser barrado.

Exercício: exercicios/07-hook-freio.md

Primeiro exercício da tarde, antes de qualquer passo que toque no Azure. O aluno pede o hook ao Claude em plan mode, registra no .claude/settings.json e testa dentro do Claude com o nome inexistente. O freio é conservador e pode barrar texto que só parece escrita; não desligue para "fazer passar". Depois do teste, o aluno faz commit do freio no próprio terminal.
