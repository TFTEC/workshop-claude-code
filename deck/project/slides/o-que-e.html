O que é o Claude Code

Um agente que trabalha no seu terminal: lê o projeto, planeja, age com ferramentas e confere o resultado.

As ferramentas dele: ler e editar arquivos, rodar comandos no terminal, buscar no código e, com MCP, falar com serviços de fora.

Exemplo: "por que este script falha?" Ele lê o script, roda, acha a linha do erro, corrige e roda de novo para conferir.

Leia mais: guia/01-o-que-e-o-claude-code.md

Antes das features, o modelo mental: o Claude Code repete este loop até terminar o pedido. Demo: numa pasta com um script pequeno e um erro de propósito, peça "por que este script falha?" e narre cada volta do loop enquanto ele lê, roda, corrige e confere. Cada funcionalidade da manhã mexe numa parte do loop: o contexto decide o que ele lê, as permissões decidem quanto ele age sozinho, a memória e as skills mudam como ele planeja, e os hooks podem barrar uma ação antes de ela acontecer.
