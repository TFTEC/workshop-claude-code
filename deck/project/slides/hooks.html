Instrução é pedido; hook é regra. Registro em .claude/settings.json, conferência com /hooks.

Leia mais: guia/05-skills-plugins-mcp-e-hooks.md · Exemplo: um hook que barra qualquer comando que apague recursos.

Demo: num projeto de teste, um hook PreToolUse simples que barra qualquer comando com "rm -rf". Mostre o registro no .claude/settings.json, o /hooks listando o hook e o Claude tentando rodar o comando e sendo barrado, com o motivo vindo do stderr. O ponto: o modelo pode ignorar uma instrução do CLAUDE.md, mas não passa por cima de um hook, porque quem roda o hook é o Claude Code. À tarde, a turma cria um hook assim para o Azure.
