AGENTS.md

Padrão aberto, lido por vários agentes. O Claude Code também lê, mas, no padrão, só quando não existe CLAUDE.md.

Para ler os dois: /config, opção Project instructions.

@AGENTS.md

Um arquivo para todos os agentes: o CLAUDE.md importa o AGENTS.md na primeira linha e acrescenta o que for só do Claude.

<!-- nota -->

Comentário HTML no CLAUDE.md sai antes de entrar no contexto: nota para humanos, sem gastar token.

Leia mais: guia/04-memoria-e-instrucoes.md

Demo: numa pasta com CLAUDE.md e AGENTS.md, rode /context e mostre que o AGENTS.md não aparece. Troque o Project instructions no /config para ler os dois, abra uma sessão nova e mostre que ele entrou. Volte ao padrão no fim, porque o /config grava no seu usuário e vale para todos os projetos. A opção /config só existe no terminal.
