Uma regra é um arquivo. Regra nova não mexe no motor.

Inspiradas no azirion, produto da TFTEC · os títulos e a KQL foram escritos para o workshop

As regras do núcleo são desperdício clássico de Azure, fácil de explicar para qualquer gestor. Os bônus ficam para quem terminar antes. Cada regra é só uma KQL do Resource Graph com um título e uma forma de estimar a economia.
