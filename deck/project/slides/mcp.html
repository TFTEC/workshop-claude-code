Demo: conecte o MCP do Microsoft Learn com o comando do slide, confira em /mcp e faça uma pergunta de Azure pedindo para usar a documentação oficial; mostre as fontes na resposta. Em seguida, a demo do Azure MCP com --read-only: claude mcp add --transport stdio azure-mcp -- npx -y @azure/mcp@latest server start --read-only, conferido com claude mcp get azure-mcp. Antes, aponte a subscription padrão do az para a do lab e devolva no fim. Não instale o plugin azure@claude-plugins-official, que liga o servidor sem --read-only.
