Skill: uma receita que o Claude segue

.claude/skills/gerar-runbook/SKILL.md

---
name: gerar-runbook
description: Gera um runbook de
  troubleshooting para um serviço
  Azure informado.
---
Escreva o runbook em markdown:
sintomas, causas prováveis,
comandos de diagnóstico e solução.

Como entra

Você digita /gerar-runbook, ou o Claude escolhe pela description.

Onde mora

No projeto, no seu usuário ou num plugin.

Quanto custa

A description fica à vista; o corpo só entra quando a skill é usada.

Leia mais: guia/05-skills-plugins-mcp-e-hooks.md

Demo: crie a pasta .claude/skills/gerar-runbook com esse SKILL.md, rode /reload-skills (pasta criada no meio da sessão precisa disso) e chame /gerar-runbook App Service. Depois, sem digitar o nome, peça "monta um runbook para o Azure SQL" e mostre o Claude escolhendo a skill sozinho pela description. Por isso a description é a parte mais importante: ela diz quando usar.
