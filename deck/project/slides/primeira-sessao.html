@README.md

Aponta um arquivo: ele entra no contexto.

!git status

Roda um comando e a saída entra na conversa. No Windows, o ! roda no Git Bash.

Alt+V

Cola o print de um erro. Fora do Windows, Ctrl+V.

Como funciona: tudo o que você aponta, roda ou cola vira contexto para o próximo passo. /clear começa do zero.

Leia mais: guia/02-sessao-contexto-e-custo.md

Demo em qualquer pasta com um projeto pequeno: um pedido em português, um arquivo com @, um comando com ! e o print de um erro colado com Alt+V, pedindo a explicação. Mostre que a saída do ! e a imagem entram na conversa e que o Claude responde em cima delas. No Windows o ! roda no Git Bash, então !Get-ChildItem falha; use !git status ou !ls. A extensão do VS Code não tem o !; no terminal integrado, sim.
